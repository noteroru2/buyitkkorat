# INDEX 350 — W2 Series & Model Release

W2 is a controlled source release of 50 commercial pages: 30 Series and 20 Model pages. It moves the architecture from 138 to 188 indexable routes.

## Important evidence note

The release is based on explicit manual approval, not on a completed real W1 performance review. The W1 observation machinery remains in the repository for historical and post-release analysis, but the release must not be described as evidence-backed by GSC unless real data is later supplied.

## Ownership model

The hierarchy remains:

```text
Core Hub → Brand → Series → Model
```

Location pages remain a separate silo. W2 does not create Series×District or Model×District combinations.

## Content and discovery gates

Each W2 page has unique title/H1, more than 1,800 body characters, product-specific valuation/photo guidance, self-canonical index/follow ownership, sitemap eligibility and at least two projected inbound discovery paths. The 50-page set has no exact duplicate body and the maximum token-set similarity remains below the 0.93 release threshold.

## Next gate

W3 stays locked until W2 passes a real Astro build, built crawl, production verification and a post-release observation period.
