# 16 — Conversion and Search Feedback Loop

```text
1 Deployment → 2 Production content verified → 3 Measurement start recorded
→ 4 GA4/GSC import → 5 Data quality → 6 Opportunity scoring → 7 Conversion compare
→ 8 Review → 9 Action → 10 New batch → 11 Observe
```

## Recommendation categories

`HOLD` · `OBSERVE` · `IMPROVE TITLE` · `IMPROVE DESCRIPTION` · `IMPROVE CONTENT` · `ADD INTERNAL LINKS` · `CLARIFY INTENT` · `CONSOLIDATE` · `ADD SUPPORTING ARTICLE` · `IMPROVE CTA` · `FIX MEASUREMENT` · `NEED MORE DATA` · `DO NOT CREATE PAGE`

## Pre/post window rules

- Separate brand vs non-brand when possible
- Separate query vs page when native evidence exists
- State search type, country/device filters, date range, freshness, privacy gaps
- Do not mix page-filtered and sitewide without labeling
- No exact join from aggregated exports
- No causation from correlation alone
