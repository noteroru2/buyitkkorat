# Location content audit

Location pages: 11. สถานะทั้งหมด: **Retain pending GSC**. เนื้อหาใช้ layout/section ร่วมสูง จึงให้ Content Quality 3 และ Requires GSC แต่ไม่ถือว่าเป็น doorway อัตโนมัติ

## Gate

- ห้าม merge/redirect/noindex จาก similarity เพียงอย่างเดียว
- ต้องมี GSC query/page อย่างน้อย 28 วันและหลักฐานนัดหมาย/โลจิสติกส์จริง
- เพิ่มเฉพาะจุดนัด/การเดินทาง/ขอบเขตบริการที่ธุรกิจตรวจสอบแล้ว
- หากไม่มีภาพพื้นที่จริง ให้ใช้ภาพบริการ generic; ห้ามสร้างภาพสถานที่หรือสาขาปลอม
