## SEO / AEO / GEO ที่แก้

1. บทความ 37 หน้าแยก Article กับ WebPage ถูกต้อง มี headline, image, author, publisher, วันที่เผยแพร่/ปรับปรุง และ mainEntityOfPage ตรง canonical
2. เพิ่มเอกสารทางเทคนิคจากแหล่งต้นทาง 51 ลิงก์ในบทความทั้ง 37 หน้า ระบุขอบเขตการอ้างอิง ไม่อ้างว่าผู้ผลิตกำหนดราคารับซื้อของร้าน
3. แสดง FAQ ที่มีอยู่ในข้อมูลบทความบนหน้าเว็บ และสร้าง schema จากข้อมูลชุดเดียวกัน
4. ผู้เขียนในบทความลิงก์กลับหน้าข้อมูลร้าน ไม่สร้างชื่อบุคลากรหรือคุณสมบัติขึ้นเอง
5. ภาพแชร์ของหน้าแรก หน้าบริการ และบทความใช้ภาพที่สัมพันธ์กับหน้า แทนภาพ default เมื่อไม่ได้ตั้งภาพเฉพาะไว้
6. ลบ W2 ออกจากหัวข้อ 27 หน้า
7. แก้ข้อความ CPU/GPU RAM/SSD ที่ไม่เหมาะกับหน้ามือถือ 12 หน้า และหน้ากล้อง 4 หน้า
8. เพิ่มตารางเช็กลิสต์ข้อมูลเฉพาะสินค้า 12 หน้า ดู [content-changes.json](content-changes.json)
9. แก้ตัวตรวจ FAQ ไม่ให้นับเครื่องหมายตกแต่ง aria-hidden เป็นส่วนหนึ่งของคำถาม และเพิ่มการตรวจคำตอบกับฟิลด์ Article เพื่อจับข้อผิดพลาดจริง
10. แก้สัดส่วนภาพ fallback เมื่อภาพต้นทางเล็กกว่าความกว้างที่ร้องขอ
