# Post-deploy monitoring

GSC access was not available in the local repository environment. First formal review: after at least 28 days of production data.

## Weekly checks

- Production route, robots and sitemap availability; indexable count remains 88.
- GSC indexing status, clicks, impressions, queries, CTR and average position by URL.
- LINE and phone conversions by landing page.
- Candidate clusters and closest competing URLs.
- Location operational evidence and actual serviceability.

## Decision gate

Retain is the default. Improve only from verified query/customer gaps. Consolidate, redirect or noindex only after 28+ days and agreement between GSC query ownership, conversion data and operational evidence. Similarity alone never qualifies.
