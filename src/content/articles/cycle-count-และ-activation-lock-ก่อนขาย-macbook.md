## Cycle Count คืออะไร

Cycle Count คือจำนวนรอบการชาร์จที่ macOS สะสมไว้ โดยประมาณหนึ่งรอบเท่ากับการใช้พลังงานแบตครบ 100% (ไม่จำเป็นต้องชาร์จจาก 0 ถึง 100 ในครั้งเดียว) ตัวเลขนี้ช่วยให้เห็นว่าแบตถูกใช้งานมามากน้อยแค่ไหนเมื่อเทียบกับอายุเครื่อง

สิ่งที่ควรจำ:

- Cycle Count สูงไม่ได้แปลว่าราคาตกเป็นจำนวนตายตัว
- Cycle ต่ำก็ยังต้องดูสภาพจอ คีย์บอร์ด พอร์ต และอาการอื่นๆ
- แบตที่เคยเปลี่ยนหรือซ่อมควรแจ้งถ้าทราบ เพราะประวัติอะไหล่มีผลต่อการพิจารณา

## วิธีดู Cycle Count บน MacBook

### ผ่าน About This Mac / System Settings

1. คลิกเมนู Apple
2. เลือก **About This Mac** (หรือ System Settings > General > About ตามเวอร์ชัน)
3. ดูรุ่น Chip/Processor, Memory, Storage ให้ครบก่อน

### ผ่าน System Information (แนะนำสำหรับ Cycle Count)

1. จาก About This Mac กด **System Report** / **More Info** แล้วเปิด System Information
2. หรือกด Option ค้างแล้วคลิกเมนู Apple แล้วเลือก System Information
3. ไปที่ **Hardware > Power**
4. ดู **Cycle Count** และข้อมูลแบตที่เกี่ยวข้อง

ถ่ายหน้าจอส่วน Power ส่งพร้อมรูปเครื่อง จะช่วยให้ประเมินเบื้องต้นเร็วขึ้น

## Activation Lock / Find My Mac — ต้องปิดก่อนขาย

Activation Lock คือการล็อกเครื่องกับ Apple ID ผ่าน Find My หากยังเปิดอยู่ ผู้รับซื้อจะตั้งค่าใหม่หรือใช้งานต่อไม่ได้ และร้านรับซื้อมักไม่สามารถปิดดีลได้จนกว่าจะปลดล็อก

### ลำดับที่แนะนำ

1. สำรองข้อมูลสำคัญ (Time Machine, iCloud, หรือคัดลอกไฟล์)
2. ออกจากแอปและบัญชีที่ผูกกับเครื่องถ้าจำเป็น
3. ปิด **Find My Mac** และ Sign Out จาก Apple ID
4. หรือใช้ Erase All Content and Settings ตามขั้นตอนของ macOS เวอร์ชันคุณ โดยใส่รหัส Apple ID เมื่อระบบถาม

แนวคิดคล้ายกับ iPhone/iPad: [วิธีออกจาก iCloud ก่อนขาย iPhone หรือ iPad](/บทความ/วิธีออกจาก-icloud-ก่อนขาย-iphone-หรือ-ipad)

### ตรวจว่าปลดล็อกแล้ว

- เปิดเครื่องแล้วเข้าหน้าตั้งค่าเริ่มต้นได้โดยไม่ถาม Apple ID เดิม
- หรือ Settings ไม่แสดง Apple ID ของคุณและ Find My ปิดอยู่

ถ้าลืมรหัสผ่าน ต้องรีเซ็ตที่ iforgot.apple.com หรือติดต่อ Apple Support ก่อนส่งมอบ — อย่าส่งเครื่องที่ยังล็อกโดยหวังว่าร้านจะปลดให้

## Intel vs Apple Silicon — โน้ตเรื่องแบตและสเปก

- **Apple Silicon (M1 / M2 / M3 ฯลฯ):** ชิป Memory Storage รวมในแพ็กเกจ การอัปเกรดหลังซื้อจำกัด แจ้ง Chip และความจุให้ตรง
- **Intel:** บางรุ่นอัปเกรด RAM/SSD ได้ แจ้งว่าเคยอัปเกรดหรือยัง
- ทั้งสองค่าย Cycle Count ยังเป็นข้อมูลอ้างอิงแบตได้ แต่ปัจจัยราคาไม่ได้จำกัดแค่แบต — รุ่น ปีจอ ความละเอียด และอาการเครื่องสำคัญเท่ากัน

อย่าใช้ตัวเลข Cycle เพื่อคาดการณ์ราคาเป็นบาทล่วงหน้า เพราะตลาดและสภาพรวมเปลี่ยนตามช่วงเวลา

## ที่ชาร์จหาย และภาษาคีย์บอร์ด

### อะแดปเตอร์ / สายชาร์จ

ไม่มีที่ชาร์จยังส่งประเมินได้ แจ้งชัดในแชทว่า MagSafe หรือ USB-C อะแดปเตอร์ครบหรือไม่ ทีมจะประเมินจากของที่มีจริง ไม่จำเป็นต้องซื้อของใหม่มาเติมก่อนขายเสมอไป

### ภาษาคีย์บอร์ด (Thai / English / อื่นๆ)

ในบางตลาดเลย์เอาต์คีย์บอร์ดมีผลต่อการหาผู้ซื้อต่อ ในบางรุ่นและบางช่วงเวลาผลอาจน้อย แจ้งว่าเป็นคีย์ไทยหรืออังกฤษตั้งแต่แรกจะดีกว่าปล่อยให้เดาจากรูป

## เช็กลิสต์ก่อนส่งประเมิน MacBook

1. ถ่าย Cycle Count จาก System Information > Power
2. ถ่าย About This Mac แสดง Chip/CPU Memory Storage
3. ยืนยันว่าปิด Find My และออกจาก Apple ID แล้ว
4. ถ่ายรูปเครื่องทุกด้าน จอเปิดติด ตำหนิใกล้ๆ
5. แจ้งอะแดปเตอร์ กล่อง และภาษาคีย์บอร์ด
