SSD เก็บรหัสผ่าน เอกสารงาน รูปครอบครัว และประวัติเบราว์เซอร์ไว้มากกว่าใครคิด การกด Delete หรือฟอร์แมตแบบผิวเผินไม่ได้ทำให้ข้อมูลหายจริง เพราะ NAND flash ใช้ TRIM และ wear leveling ทำให้การเขียนทับซับซ้อน ก่อนขาย [โน๊ตบุ๊ค](/รับซื้อโน๊ตบุ๊ค-โคราช) หรือ [คอมพิวเตอร์](/รับซื้อคอมพิวเตอร์-โคราช) ใน [นครราชสีมา](/พื้นที่/เมืองนครราชสีมา) ควรจัดการ SSD ให้ถูกต้องก่อนส่งมอบ

## ทำไม SSD ต้องจัดการต่างจาก HDD

HDD แบบเดิมลบข้อมูลด้วยการเขียนทับหรือฟอร์แมตเต็มพื้นที่ได้ค่อนข้างตรงไปตรงมา แต่ SSD มี controller ที่กระจาย บล็อกข้อมูลเพื่อยืดอายุการใช้งาน ไฟล์ที่ "ลบแล้ว" อาจยังอยู่ในบล็อกที่ระบบยังไม่เขียนทับ ซอฟต์แวร์กู้ข้อมูลจึงยังมีโอกาสอ่านได้

นอกจากนี้ BitLocker หรือ FileVault ที่เปิดอยู่ต้องปิดและถอดการเข้ารหัสก่อนรีเซ็ต มิฉะนั้นผู้ซื้อมือสองต่อไปอาจติดล็อกไดรฟ์

## วิธีลบข้อมูลบน SSD — Windows

1. สำรองข้อมูลที่ยังต้องการไป External drive หรือ cloud
2. ออกจากบัญชี Microsoft และแอปที่ sync ข้อมูล
3. ไปที่ Settings > System > Recovery > Reset this PC
4. เลือก **Remove everything** และ **Fully clean the drive** (ถ้ามีตัวเลือก)

ตัวเลือก "Fully clean" ใช้เวลานานกว่าแต่เขียนทับพื้นที่มากขึ้น เหมาะก่อนขายเครื่องที่มีข้อมูลสำคัญ

## วิธีลบข้อมูลบน SSD — macOS

1. ออกจาก iCloud และ Find My Mac
2. รีสตาร์ทกด Command + R เข้า Recovery Mode
3. Disk Utility > Erase volume เป็น APFS (Encrypted ถ้าเคยเปิด)
4. Reinstall macOS แล้วหยุดที่หน้าตั้งค่าเริ่มต้น

## Secure Erase สำหรับผู้ที่ถอด SSD ออก

หากถอด SSD ออกจากเครื่องแล้วต่อกับคอมเครื่องอื่น ใช้เครื่องมือจากผู้ผลิต:

- Samsung Magician (Samsung SSD)
- Crucial Storage Executive (Crucial/Micron)
- WD Dashboard (WD)
- Parted Magic (bootable USB สำหรับหลายยี่ห้อ)

Secure Erase สั่งให้ controller ล้างบล็อก NAND ตามมาตรฐานของชิป มีประสิทธิภาพดีกว่า quick format

## ทางเลือก: ถอด SSD แล้วขายเครื่องเปล่า

หลายคนเลือกเก็บ SSD ไปใส่เครื่องใหม่ แล้วขายตัวเครื่องพร้อม HDD เก่าหรือ SSD ความจุน้อยกว่าแทน **ต้องแจ้งทีมตั้งแต่แรก** ว่าไม่รวม SSD ตัวเดิม มิฉะนั้นราคาประเมินจะไม่ตรงกับสิ่งที่ส่งมอบ

## HDD ในเครื่องเดียวกัน

เครื่องบางรุ่นมีทั้ง SSD และ HDD — ต้องลบทั้งสองไดรฟ์ หรือถอดออกทั้งคู่ถ้าไม่ขายพร้อม HDD ที่มีข้อมูล
