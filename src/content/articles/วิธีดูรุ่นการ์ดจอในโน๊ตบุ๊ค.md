บทความนี้อธิบาย **notebook GPU** ในมุมของผู้ที่กำลังเตรียมสินค้าไอทีมือสองเพื่อขอประเมิน จุดประสงค์คือช่วยส่งข้อมูลให้ถูกชิ้นและลดความคลาดเคลื่อน ไม่ใช่สูตรรับซื้อหรือการรับประกันราคาตายตัว เพราะราคาจริงยังต้องดูรุ่น สเปก สภาพ อาการ อุปกรณ์ และการตรวจสินค้าจริง

## iGPU กับ dGPU
โน๊ตบุ๊คจำนวนมากมีกราฟิกใน CPU และการ์ดจอแยก จึงอาจเห็น GPU 0/GPU 1 ใน Task Manager การประเมิน gaming notebook ต้องรู้ dGPU ที่แท้จริง ไม่ใช่ส่งเฉพาะ Intel/AMD integrated graphics

## จุดที่ใช้ตรวจได้
ใช้ Task Manager, Device Manager, dxdiag หรือซอฟต์แวร์ของผู้ผลิตการ์ดจอเพื่อดูชื่อ GPU หากมีเครื่องหมายเตือนหรือ dGPU หาย ให้ถ่ายรูปไว้และแจ้งว่า driver/ฮาร์ดแวร์ยังไม่ได้ยืนยัน

## ชื่อ GPU ไม่บอกทุกอย่าง
RTX/GeForce/Radeon รุ่นเดียวกันใน notebook ต่างเครื่องอาจมี power limit และ cooling ต่างกัน จึงไม่ควรรับประกัน performance จากชื่อ GPU อย่างเดียว สำหรับราคาให้ดูรุ่น notebook เต็ม สเปก RAM/SSD จอ และสภาพร่วมกัน

## ส่งหลักฐานแบบสั้น
รูปหน้ารุ่นเครื่อง + Task Manager GPU + CPU/RAM/Storage + ตำหนิและ adapter ช่วยให้ประเมินได้เร็วกว่าการพิมพ์ว่า “RTX 4060” เพียงคำเดียว

## ข้อมูลที่ควรเก็บก่อนส่งประเมิน

- ถ่ายรูปชื่อรุ่น/ข้อมูลระบบที่อ่านได้ชัด
- เก็บภาพตำหนิหรือข้อความ warning โดยไม่แต่งภาพปกปิดอาการ
- จดอุปกรณ์ที่มีและสิ่งที่ขาด
- ถ้ามีประวัติซ่อมหรือเปลี่ยนอะไหล่ ให้แจ้งเท่าที่ทราบ
- สำหรับองค์กร ใช้ Serial/Asset Tag จับคู่กับรายการ แต่อย่าส่งข้อมูลผู้ใช้หรือรหัสผ่านที่ไม่จำเป็น

## สิ่งที่ไม่ควรสรุปเร็วเกินไป

ข้อมูลหน้าจอหนึ่งค่าไม่ควรถูกใช้แทนการตรวจทั้งเครื่อง เช่น health %, ชื่อ GPU, อายุประกัน หรือสถานะ “เปิดติด” ยังไม่บอกสภาพทุกฟังก์ชัน การเสนอราคาเบื้องต้นจึงต้องมีเงื่อนไขว่าตรวจจริงแล้วข้อมูลอาจต่างจากที่เห็นจากรูป

## เชื่อมไปขั้นตอนขายอย่างไร

เมื่อเก็บข้อมูลครบแล้ว ส่งรูป รุ่น สเปก สภาพ และจำนวนผ่าน LINE @buyhub เพื่อประเมินเบื้องต้น หากต้องส่งของอ่าน [ส่งสินค้าไอทีมาประเมิน](/ส่งสินค้าไอทีมาประเมิน) และหากยังไม่รู้ว่าราคาดูจากอะไรอ่าน [วิธีประเมินราคา](/วิธีประเมินราคา) เพิ่มเติม

## ความปลอดภัยก่อนส่งมอบ

สำรองข้อมูล ออกจากบัญชีที่ผูกกับเครื่อง และลบข้อมูลเมื่อถึงขั้นส่งมอบตามชนิดอุปกรณ์ ไม่ควรส่ง password, recovery key หรือรหัส OTP ให้ผู้ประเมิน หากอุปกรณ์เป็นทรัพย์สินบริษัทให้ดำเนินการตามนโยบาย การลบข้อมูลอย่างเหมาะสม และผู้มีอำนาจอนุมัติขององค์กร

## สรุป

ใช้ข้อมูลในบทความนี้เป็น checklist เพื่อยืนยันตัวสินค้าและอาการให้ชัดก่อนขอราคา การเปิดเผยข้อมูลเฉพาะที่จำเป็น ชี้ตำหนิตรงไปตรงมา และเก็บหลักฐานก่อนแพ็กช่วยลดการเปลี่ยนเงื่อนไขหลังตรวจจริง

## เช็ก Driver กับ Hardware ให้แยกกัน

ถ้า Device Manager แสดง Microsoft Basic Display Adapter หรือมีเครื่องหมายเตือน อย่ารีบสรุปว่าการ์ดจอเสีย เพราะอาจเป็น driver ที่ยังไม่ติดตั้ง ในทางกลับกัน ถ้าลง driver แล้วเกิดจอดับ artifact หรือ stress test ไม่ผ่านก็ควรแจ้งอาการตรง ๆ การประเมินจะพิจารณาทั้งการตรวจพบอุปกรณ์และความเสถียรระหว่างใช้งานจริง
