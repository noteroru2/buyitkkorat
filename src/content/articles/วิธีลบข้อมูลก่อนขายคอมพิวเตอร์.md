ก่อนขายคอมพิวเตอร์หรือโน๊ตบุ๊ค การลบข้อมูลส่วนตัวเป็นขั้นตอนสำคัญที่สุด เพราะเครื่องมักมีไฟล์เอกสาร รูปภาพ รหัสผ่าน และประวัติการใช้งาน บทความนี้อธิบายวิธีลบข้อมูลอย่างปลอดภัยสำหรับ Windows และ Mac

## ทำไมต้องลบข้อมูลก่อนขาย

- ป้องกันข้อมูลส่วนตัวรั่วไหล
- ป้องกันบัญชีธนาคาร อีเมล โซเชียลถูกเข้าถึง
- ผู้ซื้อมือสองต่อไปได้เครื่องที่พร้อมใช้งาน
- เป็นมาตรฐานที่ร้านรับซื้อคาดหวัง

## ขั้นตอนก่อนลบข้อมูล

### 1. สำรองข้อมูล

คัดลอกไฟล์สำคัญไป External HDD, Cloud หรือเครื่องใหม่ ตรวจสอบว่าสำรองครบ

### 2. ออกจากบัญชี

- Microsoft Account (Windows)
- Apple ID / iCloud (Mac)
- Google Account
- โปรแกรมที่ติดตั้งและล็อกอินไว้ (Adobe, Office ฯลฯ)
- ยกเลิกการผูกบัญชี Two-Factor Authentication ที่ไม่จำเป็น

### 3. ถอดอุปกรณ์เสริมส่วนตัว

USB ที่มีข้อมูล การ์ด SD ที่ไม่ได้ขายพร้อมเครื่อง

## วิธีลบข้อมูล Windows

### Windows 10/11 — Reset this PC

1. ไปที่ Settings > System > Recovery
2. เลือก "Reset this PC"
3. เลือก "Remove everything"
4. เลือก "Local reinstall" หรือ "Cloud download"
5. เลือก "Fully clean the drive" (ใช้เวลานานกว่า แต่ลบลึกกว่า)

### ทางเลือก: ใช้ Diskpart (ขั้นสูง)

สำหรับผู้ที่ถนัด command line สามารถลบพาร์ติชันและฟอร์แมตด้วย Diskpart

## วิธีลบข้อมูล macOS

1. ออกจาก iCloud: System Settings > Apple ID > Sign Out
2. ปิด Find My Mac
3. รีสตาร์ท กด Command + R เข้า Recovery Mode
4. Disk Utility > Erase ดิสก์ (APFS หรือ Mac OS Extended)
5. Reinstall macOS

## การจัดการ SSD และ HDD

SSD กับ HDD มีวิธีลบที่แตกต่างกัน อ่านรายละเอียด: [ssd-และข้อมูลส่วนตัวควรจัดการอย่างไรก่อนขาย](/บทความ/ssd-และข้อมูลส่วนตัวควรจัดการอย่างไรก่อนขาย)

- **SSD:** ใช้ Secure Erase หรือ Reset ที่รองรับ TRIM
- **HDD:** ฟอร์แมตเต็มหรือเขียนทับข้อมูล (DBAN สำหรับความมั่นใจสูง)

## กรณีขายคอมหลายเครื่อง

หากขายหลายเครื่องจากบริษัท ต้องลบข้อมูลทุกเครื่องและจัดทำรายการ อ่าน: [ขายคอมหลายเครื่องควรเตรียมรายการอย่างไร](/บทความ/ขายคอมหลายเครื่องควรเตรียมรายการอย่างไร)
