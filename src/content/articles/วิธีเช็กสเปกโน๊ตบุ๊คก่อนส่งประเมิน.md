การเช็กสเปกโน๊ตบุ๊คให้ถูกต้องก่อนส่งประเมิน ช่วยให้ร้านรับซื้อประเมินราคาได้ตรงและเร็วขึ้น ลดการถามซ้ำ และลดโอกาสราคาเปลี่ยนมากเมื่อตรวจของจริง บทความนี้สรุปวิธีเช็กสเปกทั้ง Windows และ Mac

## สเปกที่ควรแจ้งเมื่อส่งประเมิน

- ยี่ห้อและรุ่น (เช่น ASUS VivoBook X413, MacBook Air M1)
- CPU (เช่น Intel i5-1135G7, AMD Ryzen 5 5600H, Apple M1)
- RAM (เช่น 8GB, 16GB)
- Storage (เช่น SSD 256GB, HDD 1TB)
- การ์ดจอ (เช่น NVIDIA GTX 1650, Intel Iris Xe, ออนบอร์ด)
- ขนาดหน้าจอ (เช่น 14 นิ้ว, 15.6 นิ้ว)
- สภาพเครื่องและอาการเสีย (ถ้ามี)

## วิธีเช็กสเปก Windows

### วิธีที่ 1: Settings

1. Settings > System > About
2. ดู Device specifications (Processor, RAM)
3. ดู Windows specifications

### วิธีที่ 2: System Information

1. กด Windows + R พิมพ์ `msinfo32`
2. ดู Processor, Installed Physical Memory
3. Components > Display สำหรับการ์ดจอ

### วิธีที่ 3: Task Manager

1. Ctrl + Shift + Esc
2. Performance tab > CPU, Memory, GPU

### วิธีที่ 4: dxdiag

1. Windows + R พิมพ์ `dxdiag`
2. ดู Processor, Memory, Display

## วิธีเช็กสเปก Mac

1. Apple menu () > About This Mac
2. ดู Chip (M1, M2, Intel), Memory, Storage
3. System Report สำหรับรายละเอียดเพิ่ม

## สติกเกอร์ใต้เครื่อง

สติกเกอร์ใต้โน๊ตบุ๊คมักมีรุ่นและสเปกเบื้องต้น แต่ถ้ามีการอัปเกรด RAM หรือ SSD สเปกจริงจะต่างจากสติกเกอร์ ควรเช็กในระบบเป็นหลัก

## การ์ดจอแยก vs ออนบอร์ด

- **ออนบอร์ด:** ใช้ RAM ร่วมกับระบบ เหมาะงานทั่วไป
- **แยก (Dedicated):** มี VRAM ของตัวเอง เหมาะเล่นเกมและงานกราฟิก มีผลต่อราคามาก

อ่าน: [ปัจจัยที่ทำให้ราคาการ์ดจอมือสองแตกต่างกัน](/บทความ/ปัจจัยที่ทำให้ราคาการ์ดจอมือสองแตกต่างกัน)

## SSD vs HDD

SSD มีผลต่อราคาและความเร็ว แจ้งความจุและประเภท (NVMe, SATA) ถ้าทราบ อ่าน: [ssd-และข้อมูลส่วนตัวควรจัดการอย่างไรก่อนขาย](/บทความ/ssd-และข้อมูลส่วนตัวควรจัดการอย่างไรก่อนขาย)

2. ถ่ายรูปหน้าจอสเปกจากระบบ

## สรุป

เช็กสเปกโน๊ตบุ๊คจาก Settings, msinfo32 หรือ About This Mac แจ้ง CPU RAM Storage การ์ดจอ และสภาพเครื่องเมื่อส่งประเมิน
