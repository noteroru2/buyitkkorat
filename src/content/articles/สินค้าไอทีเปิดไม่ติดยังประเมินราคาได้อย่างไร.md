“เปิดไม่ติด” ไม่ได้แปลว่า “ขายไม่ได้” เครื่องที่ mainboard หรือแบตเสีย อาจยังมีมูลค่าในชิ้นส่วนอย่าง SSD RAM หรือการ์ดจอ หรือเหมาะซื้อเพื่อแยกอะไหล่ หากคุณอยู่ใน [นครราชสีมา](/พื้นที่/เมืองนครราชสีมา) การส่งข้อมูลครบผ่าน LINE @buyhub ช่วยให้ทีมประเมิน [โน๊ตบุ๊ค](/รับซื้อโน๊ตบุ๊ค-โคราช) หรือ [คอมพิวเตอร์](/รับซื้อคอมพิวเตอร์-โคราช) ที่เสียได้เร็วกว่าส่งแค่รูปเดียวโดยไม่บอกอาการ

## เครื่องประเภทไหนที่ยังประเมินได้

- โน๊ตบุ๊คกดเปิดไม่ติด / มีไฟแต่จอไม่ขึ้น
- PC ไม่บูต / ไม่มีเสียง POST
- มือถือเปิดไม่ติด (ต้องไม่ lock บัญชี Google หรือ iCloud)
- แท็บเล็ตเสีย
- เครื่องเกม / คอนโซลเปิดไม่ติด
- จอหรือเครื่องพิมพ์ที่ไม่ทำงาน

**ข้อยกเว้น:** เครื่องที่ lock บัญชี (FRP, iCloud lock) ต้องแก้ไขสถานะล็อกก่อน หรือแจ้งตรงตั้งแต่แรก

## อาการที่ควรอธิบายให้ชัด

| อาการ | ตัวอย่างคำอธิบาย |
|--------|----------------|
| ไม่ตอบสนอง | กด power แล้วไม่มีไฟ ไม่มีพัดลม ไม่มี LED |
| มีไฟแต่จอดำ | พัดลมหมุน แต่จอไม่แสดง |
| เปิดแล้วดับ | บูตไม่จบ รีสตาร์ทเองวน |
| เสียงแต่จอดำ | ได้ยินเสียง Windows แต่จอไม่ขึ้น |
| ตกน้ำ / ตกพื้น | แจ้งเหตุการณ์และวันที่โดยประมาณ |

ยิ่งอธิบายละเอียด ทีมยิ่งประเมินใกล้เคียงได้ แม้ราคาสุดท้ายยังต้องตรวจของจริง

## ข้อมูลรุ่นและสเปกเมื่อเปิดเครื่องไม่ได้

- ยี่ห้อ รุ่น — จากสติกเกอร์ด้านล่างโน๊ตบุ๊ค หรือกล่อง
- CPU, RAM, Storage — จากสติกเกอร์หรือใบเสร็จเก่า
- การ์ดจอ — แยกหรือออนบอร์ด (ถ้าจำได้)
- อายุการใช้งานและประวัติซ่อม

ถ่ายรูปสติกเกอร์สเปกให้อ่านได้ อ่าน: [วิธีถ่ายรูปสินค้าไอทีเพื่อให้ประเมินราคาได้เร็ว](/บทความ/วิธีถ่ายรูปสินค้าไอทีเพื่อให้ประเมินราคาได้เร็ว)

## ทำไมราคาอาจต่ำกว่าเครื่องปกติ

- ต้องลงทุนซ่อมหรือแยกชิ้นส่วน
- ไม่ทราบว่าชิ้นส่วนใดเสียจนกว่าจะทดสอบ
- ความเสี่ยงว่า mainboard หรือ CPU เสียถาวร
- แรงงานและอะไหล่ในการตรวจ

ราคาเบื้องต้นจากรูปจึงมักเป็น **ช่วงประมาณ** และปรับหลังตรวจของจริง

## ข้อมูลส่วนตัวในเครื่องที่เปิดไม่ได้

แม้เปิดไม่ติด ข้อมูลอาจยังอยู่ใน SSD/HDD

- ถอด storage ออกแล้วลบแยก (ถ้าถอดได้)
- หรือแจ้งทีมว่ายังมีข้อมูล — อย่าส่งเครื่องโดยไม่แจ้ง
