**Acer Swift** เป็นโน้ตบุ๊กพกพาที่เน้นน้ำหนักและสภาพบอดี้ หากต้องการขายในโคราช ควรส่งชื่อซีรีส์และรุ่นย่อย ไม่ใช้เพียงชื่อแบรนด์ เพราะเครื่องในซีรีส์เดียวกันอาจมี CPU, GPU, RAM, SSD และจอแตกต่างกันมาก

## ข้อมูลสำคัญก่อนประเมิน

Swift เน้นความบางเบาและการพกพา จึงควรให้ความสำคัญกับรอยบอดี้ บานพับ จอ และสุขภาพแบตมากกว่าการดูสเปกเพียงอย่างเดียว

### รูปที่ควรถ่ายเพิ่ม

ถ่ายฝาและมุมเครื่อง จอ คีย์บอร์ด บานพับ พอร์ต อะแดปเตอร์ และหน้า System Information เพื่อยืนยันขนาด/รุ่นย่อย

## หากยังไม่แน่ใจรุ่นย่อยของ Swift

หากทราบเพียงยี่ห้อ สามารถเริ่มจาก [รับซื้อ Acer โคราช](/รับซื้อโน๊ตบุ๊ค-acer-โคราช) ได้ แต่ถ้าทราบว่าเครื่องอยู่ในตระกูล **Swift** ควรส่งชื่อรุ่นย่อยและสเปกมาด้วย เพราะแต่ละตระกูลมีจุดตรวจและมูลค่ามือสองต่างกัน

## จุดที่ควรตรวจใน Acer Swift

1. **รุ่นและขนาดหน้าจอ** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
2. **CPU / RAM / SSD** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
3. **จอ บานพับ บอดี้ และพอร์ต** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
4. **แบตเตอรี่และอะแดปเตอร์** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง

ชื่อซีรีส์อย่างเดียวไม่เพียงพอสำหรับตีราคา เพราะในตลาดมือสองชุดสเปกย่อยและสภาพจริงมีผลมากกว่าการเหมาราคาเป็นรุ่นกว้าง ๆ ควรส่งภาพหน้า System Information/Task Manager หรือฉลากรุ่นถ้าดูได้

## สภาพเครื่องที่มีผลต่อราคา

ตรวจรอยตัวเครื่อง บานพับ คีย์บอร์ด ทัชแพด จอ พอร์ต สุขภาพแบต เสียงพัดลม อุณหภูมิ และอุปกรณ์ โดยเฉพาะเครื่องบางเบาควรแจ้งอาการดับ ค้าง ภาพแตก พัดลมดัง หรือเคยซ่อมระบบระบายความร้อนหากมี

หากเครื่องเป็นตระกูลอื่นในแบรนด์เดียวกัน สามารถดู [Acer Aspire](/รับซื้อโน๊ตบุ๊ค-acer-aspire-โคราช) เพื่อเช็กข้อมูลและจุดที่ควรแจ้งให้ตรงกับเครื่องมากขึ้น

1. ชื่อรุ่นเต็มและรหัสเครื่อง
2. CPU / GPU / RAM / SSD
3. รูปจอขณะเปิดใช้งานและรูปบอดี้หลายมุม
4. รูปอะแดปเตอร์และอุปกรณ์ที่มี
