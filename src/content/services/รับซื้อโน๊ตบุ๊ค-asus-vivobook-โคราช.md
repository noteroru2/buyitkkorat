**ASUS Vivobook** เป็นโน้ตบุ๊กสำหรับเรียน ทำงาน และใช้งานประจำวัน หากต้องการขายในโคราช ควรส่งชื่อซีรีส์และรุ่นย่อย ไม่ใช้เพียงชื่อแบรนด์ เพราะเครื่องในซีรีส์เดียวกันอาจมี CPU, GPU, RAM, SSD และจอแตกต่างกันมาก

## ข้อมูลสำคัญก่อนประเมิน

Vivobook มีหลายขนาดและหลายระดับสเปก ตั้งแต่เครื่องเรียนไปจนถึงรุ่นที่เน้นจอ การประเมินควรใช้รหัสรุ่นเต็มและข้อมูลจอ ไม่ควรเทียบราคาเพียงจากคำว่า Vivobook 15/16

### รูปที่ควรถ่ายเพิ่ม

ถ่ายรหัสรุ่น หน้า System Information จอพื้นสีเรียบ คีย์บอร์ด บานพับ พอร์ต และอะแดปเตอร์ หากเป็นจอ OLED หรือมีรอยกดควรถ่ายให้เห็นชัด

## หากยังไม่แน่ใจรุ่นย่อยของ Vivobook

หากทราบเพียงยี่ห้อ สามารถเริ่มจาก [รับซื้อ ASUS โคราช](/รับซื้อโน๊ตบุ๊ค-asus-โคราช) ได้ แต่ถ้าทราบว่าเครื่องอยู่ในตระกูล **Vivobook** ควรส่งชื่อรุ่นย่อยและสเปกมาด้วย เพราะแต่ละตระกูลมีจุดตรวจและมูลค่ามือสองต่างกัน

## จุดที่ควรตรวจใน ASUS Vivobook

1. **ขนาดจอและรหัสรุ่น** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
2. **CPU / RAM / SSD** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
3. **จอ คีย์บอร์ด บานพับ และพอร์ต** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
4. **แบตเตอรี่ อะแดปเตอร์ และสภาพบอดี้** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง

ชื่อซีรีส์อย่างเดียวไม่เพียงพอสำหรับตีราคา เพราะในตลาดมือสองชุดสเปกย่อยและสภาพจริงมีผลมากกว่าการเหมาราคาเป็นรุ่นกว้าง ๆ ควรส่งภาพหน้า System Information/Task Manager หรือฉลากรุ่นถ้าดูได้

## สภาพเครื่องที่มีผลต่อราคา

ตรวจรอยตัวเครื่อง บานพับ คีย์บอร์ด ทัชแพด จอ พอร์ต สุขภาพแบต เสียงพัดลม อุณหภูมิ และอุปกรณ์ โดยเฉพาะเครื่องใช้งานทั่วไปควรแจ้งอาการดับ ค้าง ภาพแตก พัดลมดัง หรือเคยซ่อมระบบระบายความร้อนหากมี

หากเครื่องเป็นตระกูลอื่นในแบรนด์เดียวกัน สามารถดู [ASUS TUF Gaming](/รับซื้อโน๊ตบุ๊ค-asus-tuf-gaming-โคราช) เพื่อเช็กข้อมูลและจุดที่ควรแจ้งให้ตรงกับเครื่องมากขึ้น

1. ชื่อรุ่นเต็มและรหัสเครื่อง
2. CPU / GPU / RAM / SSD
3. รูปจอขณะเปิดใช้งานและรูปบอดี้หลายมุม
4. รูปอะแดปเตอร์และอุปกรณ์ที่มี
