**Dell Inspiron** เป็นโน้ตบุ๊กผู้ใช้ทั่วไปที่มีสเปกย่อยหลากหลาย หากต้องการขายในโคราช ควรส่งชื่อซีรีส์และรุ่นย่อย ไม่ใช้เพียงชื่อแบรนด์ เพราะเครื่องในซีรีส์เดียวกันอาจมี CPU, GPU, RAM, SSD และจอแตกต่างกันมาก

## ข้อมูลสำคัญก่อนประเมิน

Inspiron มีทั้งเครื่องใช้งานทั่วไปและชุดสเปกที่ต่างกันตามรหัสรุ่น การมี Service Tag ช่วยให้ยืนยันเครื่องได้ง่ายขึ้น แต่ยังต้องตรวจ RAM/SSD และสภาพจริงของเครื่องที่อยู่ในมือ

### รูปที่ควรถ่ายเพิ่ม

ถ่าย Service Tag หน้า System Information จอ คีย์บอร์ด บานพับ พอร์ต และอะแดปเตอร์ หากมีการเพิ่ม RAM/SSD ควรแจ้งความจุปัจจุบัน

## หากยังไม่แน่ใจรุ่นย่อยของ Inspiron

หากทราบเพียงยี่ห้อ สามารถเริ่มจาก [รับซื้อ Dell โคราช](/รับซื้อโน๊ตบุ๊ค-dell-โคราช) ได้ แต่ถ้าทราบว่าเครื่องอยู่ในตระกูล **Inspiron** ควรส่งชื่อรุ่นย่อยและสเปกมาด้วย เพราะแต่ละตระกูลมีจุดตรวจและมูลค่ามือสองต่างกัน

## จุดที่ควรตรวจใน Dell Inspiron

1. **รหัสรุ่นและ Service Tag หากมี** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
2. **CPU / RAM / SSD / GPU** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
3. **จอ คีย์บอร์ด บานพับ และพอร์ต** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
4. **แบตเตอรี่ อะแดปเตอร์ และสภาพบอดี้** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง

ชื่อซีรีส์อย่างเดียวไม่เพียงพอสำหรับตีราคา เพราะในตลาดมือสองชุดสเปกย่อยและสภาพจริงมีผลมากกว่าการเหมาราคาเป็นรุ่นกว้าง ๆ ควรส่งภาพหน้า System Information/Task Manager หรือฉลากรุ่นถ้าดูได้

## สภาพเครื่องที่มีผลต่อราคา

ตรวจรอยตัวเครื่อง บานพับ คีย์บอร์ด ทัชแพด จอ พอร์ต สุขภาพแบต เสียงพัดลม อุณหภูมิ และอุปกรณ์ โดยเฉพาะเครื่องใช้งานทั่วไปควรแจ้งอาการดับ ค้าง ภาพแตก พัดลมดัง หรือเคยซ่อมระบบระบายความร้อนหากมี

หากเครื่องเป็นตระกูลอื่นในแบรนด์เดียวกัน สามารถดู [Dell XPS](/รับซื้อโน๊ตบุ๊ค-dell-xps-โคราช) เพื่อเช็กข้อมูลและจุดที่ควรแจ้งให้ตรงกับเครื่องมากขึ้น

## ส่งอะไรเพื่อให้ประเมินได้เร็ว

1. ชื่อรุ่นเต็มและรหัสเครื่อง
2. CPU / GPU / RAM / SSD
3. รูปจอขณะเปิดใช้งานและรูปบอดี้หลายมุม
4. รูปอะแดปเตอร์และอุปกรณ์ที่มี
5. ตำหนิ อาการเสีย ประกัน และประวัติซ่อมที่ทราบ
