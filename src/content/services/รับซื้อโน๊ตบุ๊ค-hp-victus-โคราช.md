**HP Victus** เป็นโน้ตบุ๊กเกมมิ่งที่ควรดู GPU จอ บานพับ และการระบายความร้อน หากต้องการขายในโคราช ควรส่งชื่อซีรีส์และรุ่นย่อย ไม่ใช้เพียงชื่อแบรนด์ เพราะเครื่องในซีรีส์เดียวกันอาจมี CPU, GPU, RAM, SSD และจอแตกต่างกันมาก

## ข้อมูลสำคัญก่อนประเมิน

Victus ต้องดู Product Number และ GPU ให้ชัด เพราะรุ่นขนาดใกล้กันอาจมีการ์ดจอต่างกัน สภาพบานพับ จอ และระบบระบายความร้อนเป็นอีกจุดที่ควรแจ้งตรง ๆ

### รูปที่ควรถ่ายเพิ่ม

ถ่าย Product Number หน้า CPU/GPU จอ บานพับ พัดลม/ช่องลม อะแดปเตอร์ และมุมบอดี้ หากมีอาการบานพับหลวมหรือจอกระพริบควรถ่ายวิดีโอ

## หากยังไม่แน่ใจรุ่นย่อยของ Victus

หากทราบเพียงยี่ห้อ สามารถเริ่มจาก [รับซื้อ HP โคราช](/รับซื้อโน๊ตบุ๊ค-hp-โคราช) ได้ แต่ถ้าทราบว่าเครื่องอยู่ในตระกูล **Victus** ควรส่งชื่อรุ่นย่อยและสเปกมาด้วย เพราะแต่ละตระกูลมีจุดตรวจและมูลค่ามือสองต่างกัน

## จุดที่ควรตรวจใน HP Victus

1. **CPU / GPU และ Product Number** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
2. **RAM / SSD** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
3. **จอ บานพับ พัดลม และอุณหภูมิ** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
4. **อะแดปเตอร์ แบต และสภาพบอดี้** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง

ชื่อซีรีส์อย่างเดียวไม่เพียงพอสำหรับตีราคา เพราะในตลาดมือสองชุดสเปกย่อยและสภาพจริงมีผลมากกว่าการเหมาราคาเป็นรุ่นกว้าง ๆ ควรส่งภาพหน้า System Information/Task Manager หรือฉลากรุ่นถ้าดูได้

## สภาพเครื่องที่มีผลต่อราคา

ตรวจรอยตัวเครื่อง บานพับ คีย์บอร์ด ทัชแพด จอ พอร์ต สุขภาพแบต เสียงพัดลม อุณหภูมิ และอุปกรณ์ โดยเฉพาะเครื่องเกมมิ่งควรแจ้งอาการดับ ค้าง ภาพแตก พัดลมดัง หรือเคยซ่อมระบบระบายความร้อนหากมี

หากเครื่องเป็นตระกูลอื่นในแบรนด์เดียวกัน สามารถดู [HP OMEN](/รับซื้อโน๊ตบุ๊ค-hp-omen-โคราช) เพื่อเช็กข้อมูลและจุดที่ควรแจ้งให้ตรงกับเครื่องมากขึ้น

## ส่งอะไรเพื่อให้ประเมินได้เร็ว

1. ชื่อรุ่นเต็มและรหัสเครื่อง
2. CPU / GPU / RAM / SSD
3. รูปจอขณะเปิดใช้งานและรูปบอดี้หลายมุม
4. รูปอะแดปเตอร์และอุปกรณ์ที่มี
5. ตำหนิ อาการเสีย ประกัน และประวัติซ่อมที่ทราบ
