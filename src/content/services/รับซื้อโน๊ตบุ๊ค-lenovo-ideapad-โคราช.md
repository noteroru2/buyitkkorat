**Lenovo IdeaPad** เป็นโน้ตบุ๊กสำหรับเรียนและทำงานที่มีรุ่นย่อยจำนวนมาก หากต้องการขายในโคราช ควรส่งข้อมูลระดับซีรีส์และรุ่นย่อย ไม่ใช้เพียงชื่อแบรนด์ เพราะเครื่องในซีรีส์เดียวกันอาจมี CPU, GPU, RAM, SSD และจอแตกต่างกันมาก

## มุมประเมินเฉพาะของหน้านี้

IdeaPad มีหลายสายย่อยสำหรับเรียนและทำงาน ชื่อ IdeaPad อย่างเดียวไม่พอสำหรับเทียบราคา ควรส่งรุ่นเต็มหรือ MTM และสเปกที่อัปเกรดจริง

### รูปที่ควรถ่ายเพิ่ม

ถ่าย MTM/ฉลากรุ่น หน้า CPU/RAM/SSD จอ คีย์บอร์ด บานพับ พอร์ต และอะแดปเตอร์ หากเพิ่ม RAM/SSD ควรถ่ายข้อมูลความจุปัจจุบัน


## ทำไมต้องแยกหน้า IdeaPad จากหน้า Lenovo

หน้าแบรนด์ [รับซื้อ Lenovo โคราช](/รับซื้อโน๊ตบุ๊ค-lenovo-โคราช) รับ intent กว้างของทั้งแบรนด์ ส่วนหน้านี้เน้นผู้ที่ทราบแล้วว่าเครื่องอยู่ในตระกูล **IdeaPad** จึงอธิบายปัจจัยที่ต้องเช็กในกลุ่มนี้ให้ตรงกว่า และช่วยลดการใช้เนื้อหาแบบเดียวกันกับทุกซีรีส์

## จุดที่ควรตรวจใน Lenovo IdeaPad

1. **รุ่นเต็มและ MTM หากมี** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
2. **CPU / RAM / SSD / GPU** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
3. **จอ คีย์บอร์ด บานพับ และพอร์ต** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
4. **แบตเตอรี่ อะแดปเตอร์ และสภาพบอดี้** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง

ชื่อซีรีส์อย่างเดียวไม่เพียงพอสำหรับตีราคา เพราะในตลาดมือสองชุดสเปกย่อยและสภาพจริงมีผลมากกว่าการเหมาราคาเป็นรุ่นกว้าง ๆ ควรส่งภาพหน้า System Information/Task Manager หรือฉลากรุ่นถ้าดูได้

## สภาพเครื่องที่มีผลต่อราคา

ตรวจรอยตัวเครื่อง บานพับ คีย์บอร์ด ทัชแพด จอ พอร์ต สุขภาพแบต เสียงพัดลม อุณหภูมิ และอุปกรณ์ โดยเฉพาะเครื่องใช้งานทั่วไปควรแจ้งอาการดับ ค้าง ภาพแตก พัดลมดัง หรือเคยซ่อมระบบระบายความร้อนหากมี

หากเครื่องของคุณเป็นตระกูลอื่นในแบรนด์เดียวกัน สามารถดู [Lenovo ThinkPad](/รับซื้อโน๊ตบุ๊ค-lenovo-thinkpad-โคราช) เพื่อแยก intent และปัจจัยประเมินให้ตรงกลุ่มมากขึ้น

1. ชื่อรุ่นเต็มและรหัสเครื่อง
2. CPU / GPU / RAM / SSD

4. รูปอะแดปเตอร์และอุปกรณ์ที่มี
