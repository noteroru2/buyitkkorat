**Lenovo LOQ** เป็นโน้ตบุ๊กเกมมิ่งที่ต้องแยกชุดสเปกย่อยก่อนประเมิน หากต้องการขายในโคราช ควรส่งชื่อซีรีส์และรุ่นย่อย ไม่ใช้เพียงชื่อแบรนด์ เพราะเครื่องในซีรีส์เดียวกันอาจมี CPU, GPU, RAM, SSD และจอแตกต่างกันมาก

## ข้อมูลสำคัญก่อนประเมิน

LOQ เป็นเกมมิ่งที่มีตัวเลือก CPU/GPU หลายแบบและหน้าตาใกล้กัน การส่งรหัสรุ่นและ GPU จึงสำคัญมากกว่าการบอกเพียงว่า LOQ 15

### รูปที่ควรถ่ายเพิ่ม

ถ่าย MTM/รุ่นเต็ม หน้า CPU/GPU/RAM/SSD จอ พอร์ต ช่องลม และอะแดปเตอร์ หากอัปเกรด RAM/SSD ให้แจ้งชิ้นส่วนปัจจุบัน

## หากยังไม่แน่ใจรุ่นย่อยของ LOQ

หากทราบเพียงยี่ห้อ สามารถเริ่มจาก [รับซื้อ Lenovo โคราช](/รับซื้อโน๊ตบุ๊ค-lenovo-โคราช) ได้ แต่ถ้าทราบว่าเครื่องอยู่ในตระกูล **LOQ** ควรส่งชื่อรุ่นย่อยและสเปกมาด้วย เพราะแต่ละตระกูลมีจุดตรวจและมูลค่ามือสองต่างกัน

## จุดที่ควรตรวจใน Lenovo LOQ

1. **CPU / GPU และรหัสรุ่น** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
2. **RAM / SSD และช่องอัปเกรดที่มี** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
3. **จอ พัดลม อุณหภูมิ และพอร์ต** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
4. **อะแดปเตอร์ แบต และบอดี้** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง

ชื่อซีรีส์อย่างเดียวไม่เพียงพอสำหรับตีราคา เพราะในตลาดมือสองชุดสเปกย่อยและสภาพจริงมีผลมากกว่าการเหมาราคาเป็นรุ่นกว้าง ๆ ควรส่งภาพหน้า System Information/Task Manager หรือฉลากรุ่นถ้าดูได้

## สภาพเครื่องที่มีผลต่อราคา

ตรวจรอยตัวเครื่อง บานพับ คีย์บอร์ด ทัชแพด จอ พอร์ต สุขภาพแบต เสียงพัดลม อุณหภูมิ และอุปกรณ์ โดยเฉพาะเครื่องเกมมิ่งควรแจ้งอาการดับ ค้าง ภาพแตก พัดลมดัง หรือเคยซ่อมระบบระบายความร้อนหากมี

หากเครื่องเป็นตระกูลอื่นในแบรนด์เดียวกัน สามารถดู [Lenovo IdeaPad](/รับซื้อโน๊ตบุ๊ค-lenovo-ideapad-โคราช) เพื่อเช็กข้อมูลและจุดที่ควรแจ้งให้ตรงกับเครื่องมากขึ้น

## ส่งอะไรเพื่อให้ประเมินได้เร็ว

1. ชื่อรุ่นเต็มและรหัสเครื่อง
2. CPU / GPU / RAM / SSD
3. รูปจอขณะเปิดใช้งานและรูปบอดี้หลายมุม
4. รูปอะแดปเตอร์และอุปกรณ์ที่มี
5. ตำหนิ อาการเสีย ประกัน และประวัติซ่อมที่ทราบ
