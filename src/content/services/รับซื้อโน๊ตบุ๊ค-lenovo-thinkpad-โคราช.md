**Lenovo ThinkPad** เป็นโน้ตบุ๊กธุรกิจที่ควรตรวจคีย์บอร์ด พอร์ต แบต และสถานะ BIOS หากต้องการขายในโคราช ควรส่งชื่อซีรีส์และรุ่นย่อย ไม่ใช้เพียงชื่อแบรนด์ เพราะเครื่องในซีรีส์เดียวกันอาจมี CPU, GPU, RAM, SSD และจอแตกต่างกันมาก

## ข้อมูลสำคัญก่อนประเมิน

ThinkPad เป็นเครื่องธุรกิจที่ประวัติองค์กรและสถานะ BIOS มีความสำคัญ ควรยืนยันว่าเครื่องไม่มีข้อจำกัดจากระบบเดิม และตรวจคีย์บอร์ด TrackPoint พอร์ต และแบตให้ครบ

### รูปที่ควรถ่ายเพิ่ม

ถ่าย Machine Type/Serial โดยปิดข้อมูลส่วนตัวที่ไม่จำเป็น หน้า BIOS/System Information คีย์บอร์ด TrackPoint จอ พอร์ต และอะแดปเตอร์

## หากยังไม่แน่ใจรุ่นย่อยของ ThinkPad

หากทราบเพียงยี่ห้อ สามารถเริ่มจาก [รับซื้อ Lenovo โคราช](/รับซื้อโน๊ตบุ๊ค-lenovo-โคราช) ได้ แต่ถ้าทราบว่าเครื่องอยู่ในตระกูล **ThinkPad** ควรส่งชื่อรุ่นย่อยและสเปกมาด้วย เพราะแต่ละตระกูลมีจุดตรวจและมูลค่ามือสองต่างกัน

## จุดที่ควรตรวจใน Lenovo ThinkPad

1. **Machine Type/รุ่นเต็ม** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
2. **CPU / RAM / SSD** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
3. **คีย์บอร์ด TrackPoint จอ และพอร์ต** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง
4. **แบตเตอรี่ อะแดปเตอร์ BIOS และประวัติองค์กร** — มีผลต่อความแม่นยำของราคาประเมินและการทดสอบเครื่อง

ชื่อซีรีส์อย่างเดียวไม่เพียงพอสำหรับตีราคา เพราะในตลาดมือสองชุดสเปกย่อยและสภาพจริงมีผลมากกว่าการเหมาราคาเป็นรุ่นกว้าง ๆ ควรส่งภาพหน้า System Information/Task Manager หรือฉลากรุ่นถ้าดูได้

## สภาพเครื่องที่มีผลต่อราคา

ตรวจรอยตัวเครื่อง บานพับ คีย์บอร์ด ทัชแพด จอ พอร์ต สุขภาพแบต เสียงพัดลม อุณหภูมิ และอุปกรณ์ โดยเฉพาะเครื่องธุรกิจควรแจ้งอาการดับ ค้าง ภาพแตก พัดลมดัง หรือเคยซ่อมระบบระบายความร้อนหากมี

หากเครื่องเป็นตระกูลอื่นในแบรนด์เดียวกัน สามารถดู [Lenovo IdeaPad](/รับซื้อโน๊ตบุ๊ค-lenovo-ideapad-โคราช) เพื่อเช็กข้อมูลและจุดที่ควรแจ้งให้ตรงกับเครื่องมากขึ้น

## ส่งอะไรเพื่อให้ประเมินได้เร็ว

1. ชื่อรุ่นเต็มและรหัสเครื่อง
2. CPU / GPU / RAM / SSD
3. รูปจอขณะเปิดใช้งานและรูปบอดี้หลายมุม
4. รูปอะแดปเตอร์และอุปกรณ์ที่มี
