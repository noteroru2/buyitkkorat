หากต้องการขาย **Lenovo** มือสองในโคราช ควรเริ่มจากระบุรุ่นให้ชัดก่อน เพราะคำว่า Lenovo ครอบคลุม โน้ตบุ๊กใช้งานทั่วไป ธุรกิจ เกมมิ่ง และเครื่องพกพา และแต่ละตระกูลมีตำแหน่งสินค้า ชุดสเปก และตลาดมือสองต่างกัน การประเมินที่ดีจึงไม่ควรใช้ราคาเดียวทั้งแบรนด์

## มุมประเมินเฉพาะของหน้านี้

Lenovo ควรแยก IdeaPad, ThinkPad, Legion, LOQ และ Yoga ตั้งแต่ต้น เพราะกลุ่มธุรกิจ เกมมิ่ง และผู้ใช้ทั่วไปมีจุดตรวจคนละแบบ เช่น ThinkPad มักต้องดูสถานะ BIOS/พอร์ต ขณะที่ Legion/LOQ ต้องดู GPU และระบบระบายความร้อนมากขึ้น

### รูปที่ควรถ่ายเพิ่ม

ถ่ายชื่อรุ่นหรือ Machine Type หากมี หน้า BIOS/System Information คีย์บอร์ด บานพับ พอร์ต และอะแดปเตอร์ เพื่อให้แยกเครื่ององค์กรกับเครื่องใช้งานทั่วไปได้ชัด


## ตระกูลที่ควรระบุตอนส่งประเมิน

ตัวอย่างตระกูลที่พบได้ในแบรนด์นี้ ได้แก่ **IdeaPad, ThinkPad, Legion, LOQ, Yoga** หากทราบชื่อรุ่นเต็ม รหัสรุ่น หรือข้อมูลบนฉลาก ควรถ่ายรูปส่งมาพร้อมหน้าแสดงสเปก เพื่อแยกเครื่องที่ชื่อคล้ายกันแต่รายละเอียดต่างกัน

โน้ตบุ๊กแต่ละรุ่นอาจมี CPU, GPU, RAM, SSD และจอหลายชุดสเปก การระบุรหัสรุ่นเต็มช่วยลดความคลาดเคลื่อนตอนประเมิน

## จุดที่ใช้แยกราคาของ Lenovo มือสอง

1. **ตระกูลเครื่องและรหัส MTM/รุ่นเต็ม** — ควรส่งข้อมูลหรือรูปที่เกี่ยวข้องให้เห็นชัด
2. **CPU / GPU / RAM / SSD** — ควรส่งข้อมูลหรือรูปที่เกี่ยวข้องให้เห็นชัด
3. **คีย์บอร์ด บานพับ จอ และพอร์ต** — ควรส่งข้อมูลหรือรูปที่เกี่ยวข้องให้เห็นชัด
4. **แบตเตอรี่ อะแดปเตอร์ และสถานะ BIOS** — ควรส่งข้อมูลหรือรูปที่เกี่ยวข้องให้เห็นชัด

นอกจากรายการด้านบน ยังดูสภาพโดยรวม ความครบของอุปกรณ์ ประกันที่เหลือ และความสามารถในการทดสอบเครื่องจริงด้วย เครื่องที่เปิดใช้งานและตรวจฟังก์ชันได้ครบย่อมประเมินได้แม่นกว่าเครื่องที่มีข้อมูลไม่ครบ

## สภาพแบบไหนควรแจ้งก่อน

ควรแจ้งตรง ๆ หากมีปัญหาเกี่ยวกับ **จอ บานพับ คีย์บอร์ด แบตเตอรี่ พอร์ต อะแดปเตอร์ และประวัติซ่อม** รวมถึงรอยตก รอยแตก ของเหลว ประวัติซ่อม หรืออุปกรณ์ที่ไม่ใช่ของเดิม การแจ้งก่อนช่วยให้ราคาเบื้องต้นใกล้กับผลตรวจจริงมากขึ้น
